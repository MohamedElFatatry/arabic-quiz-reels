Arabic Quiz Automation

A personal project for creating Arabic quiz videos for the iQuiz YouTube channel.

How it works

The project renders short quiz videos using GitHub Actions. Its YouTube integration allows the channel owner to authorize uploads and confirm the connected channel using the YouTube Data API.

This application is for the channel owner's personal use. It does not offer public account registration.
