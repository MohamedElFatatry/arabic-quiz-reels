Privacy policy

Arabic Quiz Automation · Updated 10 October 2026

Purpose and access

Arabic Quiz Automation is a personal tool for its owner's iQuiz YouTube channel. With the owner's explicit Google authorization, the YouTube integration accesses channel identifiers and channel details to confirm the upload destination, and uploads generated videos and their metadata. It requests the youtube.readonly and youtube.upload permissions.

Use and storage

Google user data is used only to connect the owner's channel and perform the authorized video workflow. When the integration is configured, OAuth client credentials and refresh tokens are stored in GitHub Actions repository secrets, rather than public source files. Access tokens are used during workflow runs. Generated videos and their metadata may be retained as GitHub Actions artifacts according to the repository's retention settings.

This static information website does not request Google sign-in, collect OAuth tokens, or use application analytics or advertising cookies. GitHub hosts this website and the workflow infrastructure and may process technical access logs under its own privacy policy.

Sharing and limited use

The project does not sell Google user data or use it for advertising or training AI models. Data is transmitted to Google and YouTube to perform authorized API requests and processed by GitHub to run the owner's workflow. The project's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control, revocation and deletion

The owner can revoke authorization through Google Account connections, remove stored repository secrets and workflow artifacts on GitHub, and delete uploaded videos through YouTube Studio. Revoking access stops future authorized API access; it does not automatically delete previously uploaded videos.
